## Funding Options: Pick Your Lane

*   **Path:** App Home → **[Buy Crypto]** → **[Credit/Debit Card]**.
*   Select Fiat (USD/EUR/HKD/TWD...) → Select Coin (USDT/BTC/ETH) → Enter Amount.
*   Bind Visa/Mastercard → 3D Secure Verification → Funds hit your Funding Wallet in seconds.
*   **Fees:** ~**1.8%–3.5%** (built into the exchange rate). Most expensive, but instant.
*   **Limits:** Daily limits vary by region (commonly $10k–$50k). Some domestic banks may decline crypto purchases.
*   **Best for:** First-time users, amounts < $1,000, avoiding P2P wait times.

### Option B: P2P Trading (Local Currency, Best for Direct USDT)
*   **Path:** App → **[Buy Crypto]** → **[P2P Trading]** → Buy USDT.

*   Click **[I Have Paid]** → Wait for the merchant to release coins → USDT enters Funding Wallet.
*   **Fees:** **0% on Binance's end**; the spread is baked into the merchant's price.
*   **Red Flags:** Only use in-app orders. Do not add merchants on LINE/WeChat. If the merchant fails to release, click **[Appeal]**.
*   **Best for:** Users in CN/HK/TW, mid-sized deposits, wanting USDT as a trading base.

### Option C: Crypto Deposit (Cheapest, Best for Existing Holders)
*   **Path:** App → **[Wallet]** → **[Deposit]** → Select Coin (e.g., USDT) → Select Network.
